# Panther IPA Installer PRO
1. Crea un proyecto Supabase nuevo (no ejecutar sobre las tablas antiguas). En Authentication crea tu usuario y deshabilita el registro público. Habilita TOTP MFA.
2. Ejecuta setup.sql en SQL Editor. Después ejecuta `insert into public.admins values ('TU-UUID-DE-AUTH');` sustituyendo el UUID por el de tu usuario.
3. Edita config.js con URL y clave pública anon/publishable. Nunca uses service_role. Configura los límites de almacenamiento según tus IPA.
4. Sube estos archivos a GitHub y activa Pages desde main / root. Abre admin.html, inicia sesión y registra tu autenticador TOTP. Guarda la copia de recuperación de tu autenticador.
5. Sube únicamente aplicaciones propias o autorizadas, con firma y distribución OTA válidas. El navegador no valida criptográficamente la firma. Los plist binarios requieren rellenar metadatos manualmente. El icono se carga manualmente. La barra indica etapas, no bytes. Subidas individuales; las grandes pueden requerir otro alojamiento. Las versiones privadas se guardan en bucket privado y no tienen instalación pública. No conviertas una versión pública en privada esperando revocar sus URLs: los archivos históricos públicos siguen accesibles hasta eliminarlos manualmente en Storage. Ocultar, mantenimiento y borrar catálogo tampoco revocan URLs. Las estadísticas cuentan solicitudes, no instalaciones; pueden ser manipuladas y no identifican visitantes únicos. El enlace a Telegram puede añadirse en index.html con tu URL. El QR apunta a la ficha pública. El historial guarda snapshots; la exportación no incluye archivos binarios. No se ha probado contra un proyecto Supabase real ni un iPhone.
